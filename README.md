# Rashmi's Portfolio 🌸

Personal portfolio built with React: https://rashmisingh.netlify.app/

## A little backstory

I started this project the old-fashioned way, by coding everything by hand. These days I vibe code it with AI assistance instead, mostly to save time (and because it's fun). 😄

Everything here is still my site and my content. I just have a very fast pair-programmer now.

## What's inside

- Home, About, Projects and Resume pages
- Pastel theme with a light/dark toggle
- **Mochi 🌸**, a cute scripted chatbot. No AI APIs, no tokens, no backend, just predefined answers and keyword matching

## Run it locally

Needs Node.js (v20 works well).

```bash
npm install
npm start
```

Then open http://localhost:3000.

```bash
npm run build   # production build
npm test        # run tests
```

## Built with

React, React Router, React Bootstrap, react-icons
